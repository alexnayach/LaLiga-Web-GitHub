# LaLiga-Web-GitHub

## Autores
- Alex Nayach
- Pau Pina

## Descripción
Este proyecto consiste en crear una página web sobre La Liga española de fútbol. En ella se puede encontrar información sobre algunos equipos y una selección de partidos con sus resultados de ejemplo.

## Páginas del proyecto
- **Inicio (`index.html`):** presentación de la web.
- **Equipos (`equipos.html`):** información sobre cuatro equipos de fútbol.
- **Partidos (`partidos.html`):** muestra diferentes enfrentamientos y resultados de ejemplo.

## Estructura del proyecto
```text
LaLiga-Web-GitHub/
├── index.html
├── equipos.html
├── partidos.html
├── README.md
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Tecnologías utilizadas
- HTML: estructura de las páginas.
- CSS: diseño y estilos.
- JavaScript: interacción mediante un mensaje al pulsar un botón.

## Cómo abrir el proyecto
1. Descargar o clonar el repositorio.
2. Abrir la carpeta `LaLiga-Web-GitHub`.
3. Abrir el archivo `index.html` en un navegador web.
